# Sintu Pal Portfolio

## Files
- `index.html` — portfolio content and structure
- `styles.css` — responsive styling and animations
- `script.js` — scroll reveal, typing effect and mobile navigation
- `assets/profile.jpg` — portrait extracted from the supplied resume

## Publish with GitHub Pages
1. Open the `SintuPal` repository.
2. Upload all files and folders from this package to the repository root (keep the `assets` folder).
3. Commit the changes to the branch configured for GitHub Pages (usually `main`).
4. Wait for Pages to deploy, then hard-refresh the site with Ctrl+F5.

The site uses plain HTML, CSS and JavaScript. Google Fonts are loaded from Google Fonts; the page otherwise has no framework dependency.

Personal details such as date of birth, marital status, gender and residential addresses have been left out of the public portfolio for privacy.
